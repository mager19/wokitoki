# WoKiToKi landing: nanobanana image prompts

Paste each prompt (shared blocks already expanded) into nanobanana. Save files under `landing/assets/images/` using the filename stem shown (png, jpg or webp). Attach `figures/wokitoki-box/export/wokitoki-exploded@300dpi.png` as a reference image on every prompt that shows the box. The reference is an exploded view: it is for the closed top shell and outer base only (shape, colours, button design, layout). Ignore the exploded internals (circuit boards, speaker cone, rings, the inner contents of the base tray, screws) and the separation between parts; the outer banana-yellow base band stays visible along the bottom of the assembled, closed box.

## Shared style block (paste into every prompt)

> STYLE: warm flat illustration with soft grain and gentle shading, hand-drawn feel, slightly wobbly organic outlines in dark forest green (#1F3D2B), rounded friendly shapes, simple faces (dot eyes, small smile), no gradients heavier than a soft shadow. Background is a flat warm cream (#F6EFE0) with no texture or scene clutter, so the image sits on a cream page. Palette: cream, dark green, forest green, plus small accents of pink (#F2799B), blue (#5B9BD5), green (#6BBF59), orange (#F29B38), violet (#8E6BC9), yellow (#F5C842). Everything is ILLUSTRATED: people are drawn characters; no photoreal rendering, no photo look, no 3D render of people. Leave a little empty cream margin around the subject. No text, no letters, no logos, no watermarks.

## Box description block (paste into every prompt that shows the box)

> BOX: a small friendly desktop gadget, a soft rounded rectangle about the size of a hardcover book. Off-white shell with a gentle rim line, and a banana-yellow base visible as a thin band along the bottom edge. On top, laid out left to right: a round speaker grille of small dots on the top-left; a soft frosted round light window (glowing a calm warm white) in the centre; and on the right side one big round RED arcade button (for talking) with one big round GREEN arcade button (for listening) slightly behind it. No screen, no text, no labels, no logos, no brand marks. Match the attached reference image for the closed top shell and outer base only (proportions, colours, button design, layout); ignore its exploded internals and always draw the assembled, closed box, drawn in the same flat soft illustration style.

- If a person comes out looking like a photo, add "flat vector-like children's book illustration" and regenerate.
- The box must match the closed top shell and outer base of the exploded-view figure, drawn assembled: off-white shell, banana base, red and green buttons, one light. Reject variants with screens, text or logos.
